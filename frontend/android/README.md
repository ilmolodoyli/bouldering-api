# Судейское Android-приложение 0.4.0

HTML/CSS/JS внутри WebView, Java loopback-сервер127.0.0.1:8781 на самом устройстве. Компьютер для запуска не нужен. Пакет dev.bouldering.judge/versionCode5, minSdk26/targetSdk34.

## Что работает в этой итерации
- Имя судьи локальное, НЕ защищённая авторизация.
- GET-списки участников, трасс и результатов с сервера.
- Создание участника (ФИО/возраст/категория) и трассы (сложность/возрастная категория): отдельная проверка и явное подтверждение, POST, сверка ответа и GET-readback. При неизвестном исходе автоматического повтора нет, нужно проверить список.
- Переход из списков к интерактивному учёту с настоящими участниками/трассами из базы. Выбор трассы, очередь спортсменов, срыв/зона/топ, завершённые внизу. Исходный счёт читается GET/results; при отсутствии строки после успешного полного чтения локальный учёт начинается с0. При ошибке чтения неизвестный исходный счёт НЕ заменяется0, новый ввод закрыт.
- Новые интерактивные действия сохраняются ТОЛЬКО на устройстве, явно неотправлены. Отдельный ключ от вымышленных тренировочных данных, история с before/after, экспортJSON, восстановление после перезагрузки. TOP автоматически ставит отсутствующую зону на ту же попытку, ранее взятая зона сохраняется.
- Ручной проверяемый локальный черновик результата сохранён.

## Чего сервер пока не позволяет
Проверка29.10.2026: GET/results теперь отвечает200/[], ранее500. GET/routes пуст, участников2. В OpenAPI по-прежнему НЕТ PUT/PATCH/DELETE для спортсменов и трасс, auth/version/idempotency-контракта.

Кнопки изменения/удаления открывают точную запись и честный экран неподдерживаемой операции. Удаление не выполняется, подтверждение недоступно. Экран редактирования позволяет просмотреть поля, но ничего не отправляет и не выдаёт за изменение базы. Полноценные edit/delete заблокированы до соответствующих серверных API; удалять и пересоздавать вместо редактирования нельзя.

POST/results заблокирован в UI и прокси до безопасного контракта конкурирующей записи. Эта сборка НЕ обеспечивает живую запись соревнований. Локально неотправленный учёт не синхронизируется автоматически. Имя не заменяет авторизацию. Создание участников/трасс после подтверждения создаёт РЕАЛЬНЫЕ записи, поэтому использовать только намеренные реальные данные. Разработка не отправляла тестовые записи на живой сервер.

## Сборка
JDK17+, build-tools34, platform android-34, zip/base64:
```sh
BUILD_TOOLS=/path/build-tools/34 PLATFORM=/path/platforms/android-34/android.jar KS_PASS=... bash build.sh /absolute/path/signing.jks
```
Секреты/ключ подписи и APK отсутствуют в репозитории. Общий backup не содержит ключей. Временный ключ для сборки удаляется после использования.

## 0.4.0: тестовый native APK updater

Кнопка «Обновления приложения» открывает native-диалог. Проверка фиксированного публичного GitHub Releases тестового канала, а не /latest (он исключает prerelease). Проверяется размер, SHA256 GitHub asset, package, строго больший versionCode, versionName и тот же набор сертификатов. APK загружается в закрытый cache, после передачи Android удаляется. Redirect только HTTPS на GitHub/CDN. При ошибке данные приложения не очищаются. Нет удалённой подмены web-assets.

Автообновление выключено по умолчанию. После включения проверка только при открытии приложения, не чаще 6 часов. Установка откладывается, если открыт рабочий экран. Ручная проверка доступна в любой момент; перед установкой предупреждает о закрытии приложения и предлагает экспортировать важную историю.

Первая установка 0.4.0 вручную. Разрешение Android на установку из этого источника требуется отдельно. На API31+ запрашивается USER_ACTION_NOT_REQUIRED для self-update. Android/OEM может вернуть STATUS_PENDING_USER_ACTION: открываем настоящее системное подтверждение, не утверждаем успех. На старых Android подтверждение остаётся. Root/admin/security bypass не используется.

Одинаковый package/signing key, fixed WebView origin и ключи localStorage сохраняются. Нет uninstall/clear-data. Native запуск/диалог/реальная установка 0.4.0 на телефоне ещё НЕ проверены. Проверены компиляция, подпись, discovery/download/hash и браузерная кнопка. Живой score sync/CRUD ограничения предыдущей версии сохраняются.
